# Goldschmidt

A MATLAB Live Script exploring iterative division with the Goldschmidt algorithm.

## Main File

[`Div_Calc_BUnit_S3.mlx`](Div_Calc_BUnit_S3.mlx) normalizes the divisor, updates the numerator and denominator iteratively, and compares the resulting quotient with MATLAB division. It also plots the numerator sequence.

## Getting Started

Open the Live Script in MATLAB's Live Editor. Review `z_init`, `d_init`, and `iter_cnt` to understand the input values and iteration count before running the example.

The script displays the reference quotient, the computed quotient, and their difference; results depend on the chosen inputs.
